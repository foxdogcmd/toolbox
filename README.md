# 工具箱 · PPSUC 校园工具箱

中国人民公安大学（PPSUC）校内系统的非官方 Android 客户端。把教务、学工、一卡通
这些又慢又要反复点的网页，收成手机上几个能直接用的入口。

> **非官方项目**：不是学校发布，与学校及任何校内部门没有隶属关系。
> 请只用自己的账号使用，并遵守学校的相关规定。

## 功能

| 模块 | 说明 |
|---|---|
| 成绩查询 | 教务成绩，含导航栏里藏着的分项成绩；显示各学期与总体平均学分绩点 |
| 我的课表 | 按周查看课表 |
| 校历 | 学期校历 / 周次对照 |
| 学生请假 | 清除4s阅读限制，请假表单，常用项可存成本机快速填充 |
| 空教室 | 按教学楼 / 周次 / 星期 / 节次查空闲教室 |
| 教室借用 | 从空教室直接跳到借用页，并把教学楼 / 校区 / 教室 / 周次 / 星期 / 节次回放进去 |
| 班级互评 | 实时读当前学期的测评批次与名单，逐项打分 |
| 虚拟校园卡 | 暂时只开放二维码刷卡和银行卡充值 |
| 校内网站 | WebVPN 里打开校内各站点，恢复被隐藏的任意站点访问 |

## 几个设计取舍

- **一切走 WebVPN**。`webvpn.ppsuc.edu.cn` 之外的校内域名在校外不可直连，所以所有
  请求都经 WebVPN 转发（等价于浏览器里点一遍「校外访问」），不绕过、不修改学校的
  权限与校验。
- **开屏就是统一身份认证**。本机**有存档就免登录直接放行**，没有存档才要求过真实
  认证 —— 登录前会先清掉会话 Cookie，否则上一次留下的有效会话会让 `casLogin` 跳过
  认证，输错密码也能「登进去」。密码错误会明确提示，并提醒「连续输错 10 次账号会被
  暂时冻结」。
- **数据都在本机**。学号、密码、课表、成绩、互评分数等都只存在本机，不上传任何第三方
  服务器；密码用 Android Keystore 加密后落盘，不勾「记住密码」就不写盘。
- **借用教室选到节**。跳转前先让你勾具体哪几节（默认当前时段），跳过去之后自动回填，
  不用在手机上重选一遍。
- **互评只保存、不提交**。App 里点「保存」只调草稿接口，提交必须自己去学工系统确认，
  以免误提交。
- **虚拟校园卡不扫码**。应用内没有微信环境，扫码支付直接提示「不可用」并引导去企业
  微信，不做假的成功反馈；相应地也没有打包 CameraX / ML Kit。

## 构建

需要 JDK 17 和 Android SDK（`compileSdk 34`）。

```bash
# 1. 指到本机 SDK（这个文件不入库）
echo "sdk.dir=/path/to/Android/Sdk" > local.properties

# 2. 打包
./gradlew assembleRelease        # Windows: gradlew.bat assembleRelease
```

产物：`app/build/outputs/apk/release/app-release.apk`。

release 用的是 debug 签名，方便和 debug 包互相覆盖安装、不清数据；**不要**拿它上架，
也不要拿它分发给你不信任的人。

## 环境

- Kotlin / AndroidX + Material，无第三方网络库（自己写的 WebVPN + Cookie 会话）
- `minSdk 26`、`targetSdk 34`、Java 17
- 依赖：`appcompat`、`material`、`recyclerview`、`swiperefreshlayout`
